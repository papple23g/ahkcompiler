AHK 積木使用說明

  1. 下載 Autohotkey 並安裝
  2. 組好拼圖後，點擊下載.ahk檔
  3. 開啟該檔案，選擇使用Autohotkey執行
  4. 螢幕右下角出現綠色圖示 代表腳本已成功運行中

註記

  • 修改ahk存檔後，要再對右下角的綠色圖示按右鍵>Reload，才能成功運行
