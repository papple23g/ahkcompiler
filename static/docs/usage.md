## 使用說明

<style>
.ui-infobar,.tooltip-inner,.tooltip,.tooltip-arrow::before{
    display:none;
}
</style>

 1. 下載 [Autohotkey](https://www.autohotkey.com/download/ahk-install.exe) 並安裝
 2. 點完選單或組好拼圖後，將語法複製到筆記本上儲存，副檔名需為 .ahk
 3. 開啟該檔案，選擇使用Autohotkey執行
 4. 螢幕右下角出現綠色圖示 ![](https://i.imgur.com/fKNzAz4.png =15x15) 代表腳本已成功運行中

### 註記
 - 修改ahk存檔後，要再對右下角的綠色圖示按右鍵>Reload，才能成功運行
